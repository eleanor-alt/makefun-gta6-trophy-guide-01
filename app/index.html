    Roadmap to the platinum

    One playthrough, about 200 hours by PowerPyx's estimate (250+ by Push Square's). Three stages, in order — and the only thing you must do early is in Stage 1.

    Save advice

    Missions cannot be replayed. The game gives you 15 manual save slots plus one autosave, so keep a save at the start and end of each chapter and rotate the rest during free roam. Cheats disable trophies and stop the game saving — keep them off the file you use for this run.

    Missable trophies

    Built from the official descriptions and the published guides. Only one trophy is flagged as possibly missable — and it is easy to protect.

    Looks missable, but is not

      One warning that is not about trophies

      PowerPyx reports the Irredeemable criminal profile is permanent and makes the police more aggressive. You can still earn everything, but it makes the cleanup harder — so check your criminal profile before going on a rampage.

      Sources & method

      This guide is written in its own words for this entry. It draws on the published guides below and cites them beside each trophy — a source is cited, never copied. The official names and descriptions are shown as PlayStation publishes them.

      Where each fact comes from

        What is certain, and what is not yet

        The list itself — 55 trophies, 1 platinum, 2 gold, 6 silver, 46 bronze, 28 hidden — is agreed on by every published list. The methods come from PowerPyx and the other guides, which were written in launch week; five trophies are marked in their guides as not yet confirmed, and this guide says so on each of them instead of guessing. No guide here was checked in the game by its author: where a step rests only on the official description, the guide says that too.

        What this guide is not

        No Rockstar Games logo, artwork, box art or screenshot of the game is used anywhere — the look is this guide's own. The app is static files that work with the network off: it fetches only its own data files, saves your progress in your browser (localStorage), and sends nothing anywhere.
